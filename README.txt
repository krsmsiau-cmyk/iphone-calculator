我的計算機 - iPhone PWA

這不是 IPA，而是可加入 iPhone 主畫面的 PWA。

發布到 GitHub Pages：
1. 登入 https://github.com/，建立 Public repository，例如 iphone-calculator。
2. 使用 Add file > Upload files，上傳 index.html、manifest.webmanifest、sw.js、icon-192.png、icon-512.png（不要只上傳 ZIP）。
3. Commit changes。
4. Repository Settings > Pages > Build and deployment > Deploy from a branch，選 main 和 /(root)，按 Save。
5. 等待部署完成，打開 GitHub Pages 顯示的 HTTPS 網址。
6. 在 iPhone Safari 開啟網址，點分享 > 加入主畫面 > 加入。
7. 第一次開啟並完成快取後，便可離線使用。

注意：GitHub Pages 免費網站需公開儲存庫；請勿上傳密碼或私人資料。
